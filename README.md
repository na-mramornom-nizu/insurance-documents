# Страховые документы

Веб-приложение для сотрудников СТО: заполнение и печать комплектов документов страховых компаний. Версия 1.2.1.

## Возможности

- 8 страховых компаний, 9 комплектов, 43 бланка (56 страниц).
- Единые поля для повторяющихся сведений, физические и юридические лица, представители.
- Выбор СТО, три варианта страхового случая, редактируемые обстоятельства.
- Свободные текстовые строки повреждений. Акт АльфаСтрахования сохраняет исходную таблицу: выбор детали, отметки работ слева и характер повреждений справа.
- Схемы: пустое место для бумаги, загрузка изображения или рисование.
- Локальное распознавание документов с проверкой извлечённых значений.
- Общий PDF, предпросмотр и печать; сохранение обращения в `.insurance.json` для последующего редактирования.
- Административный редактор сотрудников, паролей, реквизитов, правил и PDF-шаблонов.

## Запуск

Нужен Node.js 22 или новее. Из папки проекта:

```sh
npm ci
npm run assets
npm test
npm run build:sourcecraft
node scripts/serve.mjs
```

Открыть http://127.0.0.1:4189/insurance-documents/ . Для разработки: `npm run dev` (порт 4188).

Демонстрационные пользователи: «Администратор» и «Сотрудник», пароль `123`. В репозитории нет рабочего справочника сотрудников, их паролей и клиентских обращений.

## Публикация и общие настройки

Статическая сборка находится в `output/sourcecraft`. Файлы нужно публиковать вместе; модели распознавания, шрифты и ресурсы PDF загружаются с того же сайта. Внешняя база данных не используется. Интернет требуется на этапе подготовки ресурсов.

Администратор изменяет настройки в интерфейсе, применяет черновик, скачивает JSON или пакет и публикует его на хостинге. Скачивание не публикует изменения. Не заменяйте рабочий `settings.json` демонстрационным файлом при обновлениях.

Проверка паролей и ролей выполняется в браузере. Это ограничение интерфейса, а не защищённая серверная авторизация: хеши доступны в публичном JSON. Только административный интерфейс предоставляет изменение паролей.

## Работа с документами

После входа выберите создание нового обращения или загрузку файла `.insurance.json`. Для сохранения незавершённой работы нажмите «Сохранить для редактирования». Файл включает поля, повреждения, опись и изображения; справочник сотрудников и пароли в него не включаются. PDF предназначен для печати, а не для восстановления формы. При загрузке обращения PDF формируется заново по текущим шаблонам. Лимит файла обращения — 30 МБ.

## Проверки

83 автоматических теста: общие значения, календарные даты, геометрия и таблицы, типовые обстоятельства, свободные строки, сохранение/загрузка и отбраковка неверных файлов. Браузерные проверки выполнялись отдельно. Переполнение поля требует сокращения текста, а не скрытого обрезания.

В `public/templates` находятся подготовленные чистые бланки. Оригинальные заполненные образцы и частные скрипты их обработки не публикуются. Уведомления о лицензиях сторонних компонентов: `public/LICENSES.txt`.

## Удобство заполнения в 1.2.0

Адрес вводится одним полем без индекса. Заявитель и собственник совпадают по умолчанию; отдельные участники и водитель связываются галочками. ИНН заявителя показывается только для организации. СТО выбирается из двух предусмотренных вариантов. Номер документа ТС не запрашивается; формат VIN не проверяется. Enter добавляет строку повреждения, Shift+Enter переносит текст. На каждом шаге есть кнопка «Назад». Отметки бланков вынесены в отдельный раздел, согласия не выбираются автоматически.

73 модульных теста, 86 сценариев формирования PDF. Добавлены тесты совместимости старых файлов обращения с объединёнными адресами и отметками.

## Акт АльфаСтрахования в 1.2.1

Восстановлен оригинальный чистый бланк с 39 напечатанными деталями и тремя строками дополнительных повреждений. Сетка и названия не заменяются. Выбранная деталь и работы отмечаются слева, описание помещается в правую колонку. Для прежнего свободного текста необходимо явно выбрать строку бланка; сервис не угадывает соответствие. Дополнительные детали можно вводить вручную.

Проверены все 42 строки, пиксельное совпадение пустого результата с чистым бланком, 83 модульных теста и 86 общих PDF-сценариев.
